## Base Converter 
It is a base converter to convert something like base 10 into a number like base 16 or base 2

#### Requirements
* Python 3.0

#### Installation
* No installation needed

#### Usage 
The converter will first ask what number you want to convert, then it will ask what base the number you just entered is, then it will ask what base you want to convert to

#### How to use the program
Have a online python compiler or use visual studio code
 * For visual studio code you will need to install the python plugin for the program to run

Then just copy and paste the code into visual studio or a python compiler
